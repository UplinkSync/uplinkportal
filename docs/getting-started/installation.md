# Installation

## Requirements

- PHP `8.3+`
- WordPress `6.x`

## Steps

1. Copy this plugin to `/wp-content/plugins/uplinkportal`.
2. Activate **UplinkPortal** in WordPress Admin.
3. Add the `[uplinkportal]` shortcode to a page.
4. Open `UplinkPortal > Configuration` to complete setup.
