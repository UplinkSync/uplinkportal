# Configuration

## Configuration Hub

All primary configuration is under `UplinkPortal > Configuration`:

1. `Client Access`
2. `Modules`
3. `Security`
4. `Company Info`
5. `Portal Preview`

## Recommended Order

1. Configure Client Access mappings and role expectations.
2. Enable and review module state in the Modules tab.
3. Set security/compliance posture in Security.
4. Fill Company Info and validate Portal Preview output.
