# Quickstart

## 10-Minute Setup

1. Complete [Installation](installation.md).
2. Open `UplinkPortal > Configuration > Client Access` and verify client identity mapping.
3. Open `Configuration > Modules` and confirm required modules are enabled.
4. Open `Configuration > Security` and verify policy baseline and secret posture.
5. Open portal page with `[uplinkportal]` and confirm user access and module visibility.

## Validation

- Run the [WordPress Integration Checklist](../guides/wp-integration-checklist.md).
- Review [Troubleshooting](../troubleshooting/index.md) if validation fails.
