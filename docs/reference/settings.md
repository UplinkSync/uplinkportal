# Settings Reference

## Configuration Tabs

Primary settings are managed in `UplinkPortal > Configuration`:

1. `Client Access`
2. `Modules`
3. `Security`
4. `Company Info`
5. `Portal Preview`

## Notes

- Licensing is managed under `Configuration > Modules > Database > Licensing`.
- Entitlement-sensitive behavior is delegated to secure backend/private add-ons.
- Secret values should be stored and routed through secure abstractions, not plain options.
